# Licensing

Each distribution retains its existing license. The authoritative mapping is
`tool.omnibias.license_tiers` in `pyproject.toml`; each package includes its
license and every Python source carries an SPDX identifier.

The derivative, backend and field primitives use Apache-2.0. The convex,
discrete and SOS distributions use `AGPL-3.0-or-later OR
LicenseRef-omnibias-Commercial`. See each package's LICENSE and the unchanged
[commercial terms](COMMERCIAL-LICENSE.md). No license is changed by repository
separation. Permissive packages must not depend on copyleft packages.
