# omnibias-qcalculus

q-numbers, Gaussian binomial coefficients, Jackson derivatives and integrals, q-exponentials, and umbral algebra. The q-to-one limit recovers ordinary calculus.

Install with `pip install omnibias-qcalculus`; tensor backends are optional where
listed in [pyproject.toml](pyproject.toml).

Run package tests from the repository root:

```bash
python -m pytest packages/omnibias-qcalculus/tests -q
```

See the [main guide](../../README.md) for architecture and supported workflows.
