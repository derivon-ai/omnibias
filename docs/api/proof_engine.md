# Proof engine

A certificate router over the named collapses in
[`omnibias.core.collapse`](collapse.md). It is not a general theorem
prover. Natural language is never a premise. A caller names a finite
kind; `prove` returns a `ProofMachine` verdict plus a reason tree.

Home: `omnibias.core.proof.engine`. No new distribution.

A float residual is not a proof. `BLOCKED` is not falsity. Continuum
parents are not inferred. `theorem_prover_verified` is earned only by a
genuine `lake build`. Pairing is not a strong solution. Rank / holonomic
syzygy is not a special-function theorem.

The `gap` *kind* is Enclosure Collapse of a claimed `OPT` sandwich. It
does not register `gap_collapse`.
