# Jet-bundle vocabulary (01-10)

A **dictionary**, not a discovery, and **not** an `omnibias-jetbundle`
package. It names what omnibias already computes. Founding `delta -> 0`
produces fiber coordinates; temperature collapse acts on the base
stratification.

G1/G2 are CI-gated on the contact smoke: `is_holonomic` on 220
randomized genuine versus corrupted towers with zero
misclassifications, and second-order versus first-order residual
rates over three halvings. G3 vocabulary coverage is not in CI
`all_passed`. No performance claim. Status is **gated**. The
canonical write-up is [theory-jets.md](../theory-jets.md).
