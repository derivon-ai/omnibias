# Arrangement-adapted SOS bases (07-05)

A Positivstellensatz certificate is limited by the monomial
vector. When positivity is hardest on a cell of a hyperplane
arrangement, extra pure powers of the arrangement coordinates
let the same polynomial certify at a lower ambient degree
than the total-degree basis.

This chooses tightness, never soundness. Failures are
reported (G5), not excluded. Status is **gated**. The parent
spectral-gap / Yang-Mills questions stay external.

Home: `omnibias.sos.monomials.arrangement_adapted_basis`.
No new package.
