# Nobel-adjacent domain programs (07-07)

Three **tools**: an exact oscillator ladder inside a
variational ansatz, a Harris-sheet resistive-layer residual,
and exact `dT/dθ` through a transfer product. The founding
bias collapse (`delta -> 0`) supplies the operators.
Temperature collapse (`beta -> inf`, feasibility) does not
appear. Do not conflate the two.

Status is **shipped**. G0–G6 are CI-gated as
empirical tooling results. "Nobel-adjacent" names the
domains, not the results.

This is not a many-body solution, not a fusion-energy
result, and not a new material. Parent scientific problems
stay external obligations.

Homes: `omnibias.ferminet.hermite`, `omnibias.pinn.plasma`,
`omnibias.pinn.stack`. No new package.
`theorem_prover_verified` is not asserted.
