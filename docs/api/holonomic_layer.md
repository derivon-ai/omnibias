# Holonomic layer (09-12)

A block whose weights **are** Ore coefficients. Forward prolongs the
unique D-finite jet of `L u = 0` from an initial jet. Representable
maps are D-finite by construction.

This block is not founding bias collapse. A `sigma` net may still
supply the data jet via founding bias collapse (`delta -> 0`).
Temperature collapse (`beta -> inf`, feasibility) does not appear.
Do not conflate the two.

Status is **gated**, not shipped. D-finite class only. Not a general
PINN. Not CCF stretch. Lean flags are 09-26, not asserted here.

Home: `omnibias.holonomic._core.layer`.
