# Arrangement geometry (01-03)

Many soft hyperplanes, not one. Cell membership is **temperature**
collapse (`beta -> inf`), not founding `delta -> 0`. Sampling is a
subgraph / lower bound, never a complete face lattice. The gap
certificate is sound, not a P vs NP claim and not
`theorem_prover_verified`. The binary tree is the special case that
agrees with `partition_weights`.

G1 combinatorics (`n<=12`, `D<=4`), G2 gap soundness, and G3 vs
`partition_weights` (<= 4 ulp) are CI-gated. G4 parity is CI-gated.
Status is **gated**, not shipped. See theory spec 01-03. No
`omnibias-arrangement` package.
