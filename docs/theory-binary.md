# Differentiable binarization: the surrogate-gradient tower

This page gives the theory behind omnibias's view of **binary / quantized neural
networks**. The one-line thesis:

> The straight-through estimator (STE) is not a hack. It is the lowest-order,
> uniform-kernel, unit-bandwidth corner of a **closed-form family** of surrogate
> gradients generated by the bias-collapse derivative tower of a single smooth
> base activation. omnibias spans that whole family — and, uniquely, can *certify*
> statements about it with interval arithmetic and a Lean kernel.

It pairs with the runnable benchmark in
[`examples/binary_vs_ste`](cookbook/better-than-ste-binary.md) and the OMBU
derivative-tower primer in [the main theory page](theory.md).

## 1. The hard unit and the impossibility

A binarized unit applies the hard sign (the `{0,1}` Heaviside twin is identical up
to an affine map):

\[
b(z) = \operatorname{sign}(z) \in \{-1, +1\}, \qquad b'(z) = 2\,\delta(z).
\]

Its classical derivative is \(0\) almost everywhere plus a Dirac at the boundary —
useless for gradient descent. People "fix" this with the STE: keep the hard
forward, but pretend the backward is the clipped identity \(\mathbf 1_{|z|\le 1}\).
This looks arbitrary. The first result is that it is *forced*:

!!! note "Proposition 0 (why you must break forward ≡ backward)"
    No single \(C^1\) function is simultaneously **exactly hard** (codomain
    \(\{-1,+1\}\)) and has an **informative gradient** (non-zero on a set of
    positive measure). Proof: a \(C^1\) map into the two-point set \(\{-1,+1\}\) is
    locally constant, hence has zero derivative everywhere on a connected domain.

So every method that trains hard networks with gradients breaks the
forward-equals-backward identity *somewhere*. There are exactly three places to
break it, and §2 shows they are the same object viewed three ways:

| where the break lives | method | forward | backward |
| --- | --- | --- | --- |
| in the VJP | **surrogate / STE** | hard | mollified |
| deferred to \(\beta\!\to\!\infty\) | **soft relaxation + anneal** | \(\sigma(\beta z)\) | its own derivative |
| in the expectation | **stochastic binary neuron** | hard *samples* | \(\nabla\) of the mean |

A common intuition is "use \(\lim_{\beta\to\infty}\sigma(\beta z)\) in the forward
so we optimise the *real* network, not a surrogate." But that limit **is** the
step (the same function, not a softer one), so it returns zero gradient. You cannot
escape Proposition 0 by taking the limit; you can only choose where to break.

## 2. The surrogate is the exact gradient of a mollified network

Let \(\varphi \ge 0\) be a symmetric probability density (\(\int\varphi = 1\)) and
write the bandwidth-\(\beta\) **mollifier** \(\varphi_\beta(z) = \beta\,\varphi(\beta z)\).
Define the mollified unit \(b_\beta = b * \varphi_\beta\) (convolution).

!!! abstract "Theorem 1 (surrogate = mollified gradient; STE = uniform kernel)"
    For every symmetric density \(\varphi\),
    \[
    b_\beta \xrightarrow[\beta\to\infty]{} b \ \text{pointwise}, \qquad
    b_\beta'(z) = (b' * \varphi_\beta)(z) = 2\,\varphi_\beta(z) = 2\beta\,\varphi(\beta z).
    \]
    Hence the surrogate backward \(g(z) \propto \varphi(\beta z)\) **is the exact
    derivative of the \(\varphi\)-mollified network**. The omnibias kernels are
    exactly these densities:

    | kernel | \(\varphi(u)\) | smooth CDF \(=\) forward it mollifies |
    | --- | --- | --- |
    | `box` (**STE**) | \(\tfrac12\mathbf 1_{|u|\le 1}\) | hard-tanh |
    | `tanh` | \(\tfrac12\operatorname{sech}^2 u\) | \(\tanh\) |
    | `logistic` | \(\sigma(u)\,(1-\sigma(u))\) | logistic |
    | `gaussian` | \(\tfrac{1}{\sqrt{2\pi}}e^{-u^2/2}\) | probit |
    | `cauchy` | \(\tfrac{1}{\pi(1+u^2)}\) | arctan |

    So **STE is the special case \(\varphi = \text{uniform}\)** — the crudest
    (compact-support, discontinuous) member of the family.

Equivalently (the third row of the table in §1): inject noise with density
\(\varphi\) into the pre-activation of a *stochastic* binary neuron. Its expected
output is \(b_\beta\) and its mean-field gradient is the surrogate. **The surrogate
is therefore the honest gradient of a real (stochastic) model, not a fiction.**

!!! warning "What autodiff actually computes"
    There is no hidden numerical error in a custom surrogate backward. PyTorch / JAX
    compute the VJP exactly. The only gap is the *modelling* bias \(b_\beta - b\)
    (forward and backward are different functions), which Theorem 1 makes explicit
    and §5 bounds rigorously. "Autodiff is unfriendly to surrogates" is a category
    error: autodiff faithfully differentiates the mollified network; you deploy the
    hard one.

The shipped `omnibias.binary.{torch,jax}.binarize` realises the `tanh` member with the
\(\beta\)-exact scaling \(g(z) = \beta\,(1-\tanh^2\beta z)\); the benchmark's
`kernels.py` exposes the rest (peak-normalised, so \(\beta\) sets only the width).

## 3. Bias-collapse unifies forward, backward, and curvature

The omnibias primitive (see [theory.md](theory.md)) is the multi-bias unit
\(f_K(z) = \sum_k s_k\,\sigma(z+b_k)\), which on the central-difference stencil
collapses to the \((K{-}1)\)-th derivative of the base:
\(f_K(z) \to \sigma^{(K-1)}(z + \bar b)\). Overlay the binary unit on this tower and
the apparent "two different functions" of §1 become **siblings on one tower of a
single base \(\sigma\)**:

| role in the binary unit | bias-collapse order | object |
| --- | --- | --- |
| forward | order \(0\), pushed to \(\beta\to\infty\) | \(\sigma \to\) step |
| slope backward (the surrogate) | order \(1\) (\(K=2\) collapse) | \(\sigma'\) |
| curvature backward (jet-STE) | built from order \(3\) | \(\sigma'''\) |

This is why the surrogate is principled: forward and backward are not an arbitrary
pair, they are \(\sigma\) and its mollified derivative — adjacent rungs of the same
closed-form ladder. A binarized unit is then a single point on a **three-axis
design manifold**:

| axis | meaning | STE's coordinate |
| --- | --- | --- |
| base \(\sigma\) | mollifier density \(=\) robust-loss role (§6) | uniform |
| collapse order \(K\) | slope (1) vs curvature-corrected (3) backward | 1 |
| bandwidth \(\beta\) | mollifier scale \(= 1/\)window | \(\approx 1\) |

STE \(=\) (uniform, order 1, \(\beta\!\approx\!1\)); Gumbel-Softmax / Concrete \(=\)
(logistic, stochastic, annealed). omnibias provides the whole manifold in closed
form, with the derivative tower from one `tanh`/`sigmoid`/`exp` evaluation.

## 4. The jet-STE is provably higher-order accurate

The "ideal" backward at window half-width \(h = 1/\beta\) is the window-averaged
slope of the smooth surrogate \(s(z) = \tanh(\beta z)\):

\[
\overline{s'}(z) = \frac{1}{2h}\int_{-h}^{h} s'(z+u)\,\mathrm du
= s'(z) + \frac{h^2}{6}\,s'''(z) + \frac{h^4}{120}\,s^{(5)}(z) + \dots
\]

(odd terms integrate to zero). The plain surrogate uses \(s'(z)\) and so misses
\(\overline{s'}\) by \(O(h^2)\). The **curvature-corrected** slope used by
`binarize_curvature` is \(s'(z) + \tfrac{h^2}{6}s'''(z)\).

!!! abstract "Theorem 2 (jet-STE is a 4th-order quadrature)"
    \[
    \overline{s'}(z) - \Big(s'(z) + \tfrac{h^2}{6}s'''(z)\Big)
    = \frac{h^4}{120}\,s^{(5)}(z) + O(h^6) = O(h^4).
    \]
    The curvature correction reduces the bias against the mollified gradient from
    \(O(h^2)\) to \(O(h^4)\) — a two-order improvement, practical only because
    omnibias computes \(s'''\) (and \(s^{(5)}\) for the remainder bound) in closed
    form from one `tanh` call via the Riccati tower
    (`omnibias.binary.torch.ops.surrogate.curvature_corrected_slope`).

The remainder is finite and certifiable, not merely asymptotic — see §5.

## 5. The dead-unit dichotomy, and why heavy tails win

A unit at pre-activation \(z\) receives backward signal \(\propto \varphi(\beta z)\).
The *support and tail* of \(\varphi\) therefore decide whether a unit can ever
recover once batch-norm pushes it away from the boundary.

!!! abstract "Theorem 3 (freezing dichotomy)"
    - **Compact support (STE box).** If \(\operatorname{supp}\varphi = [-1,1]\),
      every unit with \(|z| > 1/\beta\) gets **exactly zero** gradient. It is frozen
      until *other* units move its pre-activation back inside the window; under
      batch-norm at unit scale with \(\beta = 1\) a large fraction sit outside it.
    - **Full support (`tanh`, `gaussian`, `cauchy`).** If \(\varphi > 0\)
      everywhere, **no unit is ever frozen**. Moreover the recovery strength at
      distance \(z\) is set by the tail:
      \[
      \varphi_{\text{cauchy}}(z) \sim \frac{1}{\pi\beta^2 z^2}
      \;\gg\;
      \varphi_{\text{gauss/tanh}}(z) \sim e^{-\Theta(\beta^2 z^2)}\ \text{or}\ e^{-\Theta(\beta|z|)}
      \;\gg\;
      \varphi_{\text{box}}(z) = 0 .
      \]

So the certified reanimation ranking is **cauchy \(\gg\) gaussian/tanh \(\gg\)
box (STE) = 0** in the tail. This is the rigorous core of the empirical result that
the heavy-tailed kernel is the strongest arm on the hardest dataset, and that an
over-sharp \(\beta\) (a *narrow* window) is the dominant failure mode.

## 6. Surrogate design = robust-estimator design

The backward kernel \(\varphi\) is, exactly, an **IRLS weight**. For a robust loss
\(\rho\) with influence \(\psi = \rho'\), the iteratively-reweighted-least-squares
weight is \(w(r) = \psi(r)/r\). The omnibias
[activation dictionary](theory.md) already records this correspondence at the
\(K=2\) collapse:

| kernel \(\varphi\) | robust loss \(\rho\) | statistical role |
| --- | --- | --- |
| `box` | (none — hard trim) | non-robust, breaks down past \(\pm 1/\beta\) |
| `tanh` (\(1-\tanh^2\)) | log-cosh-type | bounded-influence, symmetric |
| `gaussian` | Welsch / Leclerc | redescending, fast cutoff |
| `cauchy` (\(1/(1+u^2)\)) | Cauchy / Lorentzian | redescending, heavy-tailed |

!!! tip "The reframing"
    Choosing a surrogate-gradient kernel **is** choosing the robust estimator whose
    reweighting step the backward implements. **Dead units are the breakdown point
    of a non-robust (compact-support) weight**; heavy-tailed kernels are robust to
    "outlier" saturated units, which is why `cauchy` reanimates them. Surrogate
    design inherits a century of M-estimation theory.

## 7. \(\beta\)-annealing is graduated non-convexity

Let \(L_\beta(\theta)\) be the loss of the \(\varphi_\beta\)-mollified network.
Then \(L_\beta \to L_\infty\) (the hard objective) as \(\beta \to \infty\), and for
small \(\beta\) the landscape is smoother / flatter.

!!! abstract "Theorem 4 (annealing is a homotopy / GNC continuation)"
    Increasing \(\beta\) over training is a graduated-non-convexity continuation of
    \(\{L_\beta\}\). The correct schedule goes **soft → mildly sharp**
    (\(\beta_{\text{start}} \approx 0.5 \to \beta_{\text{end}} \approx 3\)): it must
    *not* drive \(\beta\) far past the data scale, because by Theorem 3 that
    reintroduces the non-smooth hard objective **and** starves gradients.

This explains the benchmark's `anneal` failure in the mis-scaled regime
(\(\beta: 10 \to 100\)) as a *theorem violation*, not bad luck: it anneals in the
wrong direction relative to the activation scale.

## 8. Certified statements (the part only omnibias can make)

Generic deep-learning frameworks can assert these facts empirically. omnibias can
**prove** finite instances of them with the rigorous interval kernel
(`omnibias.core.verified`) and discharge the rational obligations through the Lean
kernel (`omnibias.core.proof`). The
[`omnibias.verify._core.surrogate_bounds`](api/verify.md) module (re-exported at
the `omnibias.verify` top level) emits, with outward rounding:

- **Mollification margin** (Theorem 1). For \(|z| \ge d\), a rigorous enclosure of
  \(\tanh(\beta d) - \tfrac12\); when its lower endpoint is positive, the Lean
  kernel proves the hard/smooth agreement margin beyond \(d\) exceeds \(\tfrac12\).
- **No-dead-unit / freezing** (Theorem 3). A two-sided enclosure of the kernel
  \(\varphi_\beta\) on a box. For `cauchy`/`tanh` on a finite box the lower endpoint
  is provably positive (Lean: \(0 < \varphi\) everywhere on the box → no dead unit);
  for `box` beyond its support the enclosure is exactly \(0\) — the contrast is
  machine-checked, not asserted.
- **Lipschitz bound.** The mollified forward \(s = \tanh(\beta z)\) is \(L\)-Lipschitz
  with a certified \(L \le \beta\) (the kernel's certified supremum).
- **Jet remainder** (Theorem 2). A rigorous enclosure of
  \(\overline{s'} - (s' + \tfrac{h^2}{6}s''')\) showing it lies in an explicit
  \(O(h^4)\) interval, via the order-5/6 interval tower.

These turn "STE is experimental folklore" into kernel-checked theorems on finite,
honestly-scoped instances.

## 9. Falsifiable predictions

The framework makes predictions the benchmark is designed to test:

1. **Width, not magnitude, dominates under Adam.** Adam's per-coordinate
   normalisation divides out the global scale, so peak-normalised (`tanh`) and
   \(\beta\)-exact (`omnibias_b1`) arms should match, while a too-large \(\beta\)
   (`omnibias_b10`) should *trail the STE*.
2. **Heavy tails help most where units saturate** — i.e. the `cauchy` advantage
   grows MNIST → Fashion-MNIST → CIFAR-10.
3. **Curvature correction helps in the small-window regime** (large \(\beta\)),
   where the \(O(h^2)\) bias it removes is largest.

## 10. What is established vs new

- **Established**: mollified/smoothed gradients; the Concrete/Gumbel-Softmax
  relaxation; "STE is a biased estimator"; graduated non-convexity; M-estimation /
  IRLS.
- **The omnibias contribution**: (a) forward + slope + curvature as **one
  closed-form bias-collapse tower** of a single base, with the surrogate \(=\) the
  \(K{=}2\) collapse output; (b) the **jet bias-order theorem** (§4), practical only
  with the closed-form \(s'''\); (c) the explicit **kernel ↔ robust-IRLS** dictionary
  (§6); (d) **certified** finite instances of all of the above via interval
  arithmetic and a Lean kernel (§8) — which no other BNN framework offers.
