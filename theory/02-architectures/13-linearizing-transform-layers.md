# 02-13 Linearizing transform layers

## 1. Thesis and status

Cole-Hopf, Miura, Backlund and Darboux are **exact algebraic maps between
equations**, and every operation they need — multiply, reciprocal, exponential,
logarithm, differentiate, integrate — is available exactly on jets, so a layer
can carry a nonlinear problem into a linear one, solve it there, and map back
with no approximation anywhere in the transform.

- **Status**: designed
- **Depends on**: 01-01, 01-09, 02-09, 03-11
- **Blocks**: 07-02

  `derivative_jet`, `antiderivative_jet`, `compose_jet`, `affine_jet`,

- Spec 02-09 — the tanh-method ansatz, which is the single-soliton case these
  transforms generalize.

**Confirmed gap.** No Cole-Hopf, no Miura, no Backlund, no Darboux code exists.
The jet operations that make them exact are all present and have never been used
for this.

## 4. Mathematics

### Cole-Hopf

Viscous Burgers

```
u_t + u u_x = nu u_xx
```

becomes the linear heat equation under

```
u = -2 nu ( log phi )_x = -2 nu phi_x / phi      =>      phi_t = nu phi_xx
```

This is the flagship case because the heat equation is solvable in closed form
for arbitrary initial data, so **Cole-Hopf turns a nonlinear problem into a
convolution**.

In jet terms the map is: take the jet of `phi`, apply `jet_reciprocal`, multiply
by the jet of `phi_x` (which is `derivative_jet` of the same jet), scale. Every
step is exact, and the inverse map `phi = exp( -(1/(2 nu)) integral u dx )` uses
`antiderivative_jet` and `jet_exp`.

### Miura

The Miura transform links mKdV and KdV:

```
v_t - 6 v^2 v_x + v_xxx = 0    (mKdV)
u = v^2 + v_x                  (Miura)
=>  u_t - 6 u u_x + u_xxx = 0  (KdV)
```

The verification is a short computation, and in jets it is `jet_multiply` plus
`derivative_jet`. Its significance: solutions of mKdV map to solutions of KdV,
so a solver for one gives a solver for the other, and the Miura map is the
origin of the modern integrability theory.

### Backlund and Darboux

A Backlund transformation relates two solutions of the same (or a related)
equation through a pair of first-order relations. For sine-Gordon
`u_{xt} = sin u`, the classical pair is

```
( (u_1 - u_0)/2 )_x = a sin( (u_1 + u_0)/2 )
( (u_1 + u_0)/2 )_t = (1/a) sin( (u_1 - u_0)/2 )
```

Given one solution `u_0` (for example the trivial `u_0 = 0`), integrating the
pair produces a new solution `u_1` (a one-soliton), and iterating produces
`n`-solitons **by algebra**, through the nonlinear superposition (permutability)
formula

```
tan( (u_3 - u_0)/4 ) = ( (a_1 + a_2)/(a_1 - a_2) ) tan( (u_1 - u_2)/4 )
```

which requires no integration at all. That is the point: **multi-soliton
solutions are generated by an algebraic recursion**, and every step is a jet
operation.

Darboux transformations do the same at the level of the associated linear
(Lax) problem, dressing a known eigenfunction into a new potential.

### Why jets make this exact

Each transform is a finite composition of: multiplication, reciprocal,
exponential, logarithm, differentiation, integration, and (for Backlund)
trigonometric functions of jets. All are exact on truncated Taylor jets:

| Operation | Jet primitive | Exact? |
|---|---|---|
| product | `jet_multiply` (Cauchy product) | yes, to truncation order |
| reciprocal | `jet_reciprocal` | yes |
| exponential | `jet_exp` | yes |
| derivative | `derivative_jet` (shift and scale) | yes |
| antiderivative | `antiderivative_jet` | yes up to the constant |
| composition | `compose_jet` (Faa di Bruno) | yes |

"Exact to truncation order" is the honest qualifier: a jet of order `N` carries
`N + 1` coefficients, and the transform is exact on those. It is not a
symbolic-algebra system; it is exact truncated Taylor arithmetic, which is
enough for residual evaluation and for verifying a transform's correctness order
by order.

### What this buys operationally

Two distinct wins, which must not be conflated.

1. **Exact residual transport.** If the transformed problem is linear, its
   residual is linear in the transformed variable, so training is far better
   conditioned. Cole-Hopf on Burgers converts a shock-forming nonlinear residual
   into a smooth heat residual.
2. **Exact solution generation.** Where the classical formula gives an exact
   solution (heat kernel after Cole-Hopf, `n`-soliton after Backlund), the
   result is exact, verifiable symbolically, and available as a benchmark
   reference with zero discretization error.

## 5. Worked example

**Cole-Hopf, checked on a heat solution.**

Take `nu = 1` and the heat solution `phi(x, t) = 1 + exp(x + t)`. Check
`phi_t = phi_xx`: `phi_t = e^{x+t}` and `phi_xx = e^{x+t}`. Yes.

Cole-Hopf gives

```
u = -2 phi_x / phi = -2 e^{x+t} / ( 1 + e^{x+t} )
```

At `x = 0, t = 0`: `e^0 = 1`, so `u = -2 / 2 = -1`.

Verify Burgers `u_t + u u_x = u_xx` at that point. Write `E = e^{x+t}`,
`S = 1 + E`, so `u = -2 E / S`. Note `dE/dx = dE/dt = E` and `dS/dx = E`.

```
u_x = -2 ( E S - E * E ) / S^2 = -2 E ( S - E ) / S^2 = -2 E / S^2
u_t = u_x                                         (u depends on x + t only)
u_xx = -2 ( E S^2 - E * 2 S E ) / S^4 = -2 E ( S - 2E ) / S^3
```

At `x = t = 0`: `E = 1`, `S = 2`:

```
u    = -2 * 1 / 2       = -1
u_x  = -2 * 1 / 4       = -0.5
u_t  = -0.5
u_xx = -2 * 1 * (2 - 2) / 8 = 0
```

Burgers residual:

```
u_t + u u_x - u_xx = -0.5 + (-1)(-0.5) - 0 = -0.5 + 0.5 - 0 = 0
```

Exactly zero. A nonlinear PDE solution obtained from a linear one by an
algebraic map, verified by hand.

Note the structure: `u = -2E/S = -2(1 - 1/S)`, which is `-1 - tanh((x+t)/2)`
after rewriting — a travelling front. So Cole-Hopf on this heat solution
reproduces exactly the tanh-class travelling wave of spec 02-09, which is the
consistency check between the two specs.

**Backlund permutability, counted.** For sine-Gordon, generating a two-soliton
from two one-solitons via the permutability formula requires one `tan`, one
`arctan`, and four arithmetic operations: `O(1)` work, no integration, no
solving. Generating the `n`-soliton is `O(n^2)` such steps. Compare with a
numerical solve of the sine-Gordon initial value problem to comparable accuracy,
which is `O(N_x N_t)` with a discretization error floor. The algebraic route has
no discretization error at all.

## 7. Practical use cases

1. **Burgers without the shock problem.** Train `phi` on the heat equation,
   where the solution is smooth and the residual is linear; recover `u` with its
   shock exactly. This directly targets the hardest part of the existing Burgers
   example.
2. **Exact reference solutions for benchmarks.** `n`-soliton solutions with zero
   discretization error, generated algebraically.
3. **Initialization and pretraining.** Start a general solver from an exact
   transformed solution and learn only the deviation.
4. **Integrability testing.** If a Miura-type or Backlund-type transform can be
   found for a discovered equation (with spec 03-11's symmetry machinery), the
   equation is a strong integrability candidate.
5. **Inverse scattering adjacency.** Darboux dressing is the algebraic core of
   inverse scattering; having it exactly opens that route without a full IST
   implementation.

## 8. Acceptance gates

Baselines: a direct PINN on the nonlinear equation, and a high-resolution
numerical solve.

- **G1 transform verification.** For each of Cole-Hopf, Miura and the
  sine-Gordon Backlund pair, `verify_transform` returns `True` with the target
  residual identically zero as a jet identity to order 8, using exact rational
  arithmetic where the coefficients allow.
- **G2 exact solution generation.** Generated `n`-soliton solutions for
  `n = 1, 2, 3` satisfy the PDE to `<= 1e-13` relative on a dense space-time
  grid, and their asymptotic phase shifts match the published formulas.
- **G3 Burgers win.** A Cole-Hopf-trained field reaches relative `L2 <= 1e-8` on
  a shock-forming Burgers problem, at least `100x` better than the direct PINN
  baseline at matched cost, over five seeds.
- **G4 permutability.** The two-soliton produced by the permutability formula
  agrees with the two-soliton produced by two sequential Backlund integrations
  to `<= 1e-12`.
- **G5 negative control.** `verify_transform` returns `False` for a deliberately
  perturbed transform (a wrong coefficient), so the checker is not vacuous.
- **G6 parity.** torch and jax bit-identical.

## 10. Honesty and scope

- No collapse limit appears here. These are algebraic transforms on jets, not
  statements about coalescing biases (`delta -> 0`) or hardening gates
  (`beta -> inf`).
- **Exactness is to truncation order.** Jet arithmetic carries `N + 1`
  coefficients; the transforms are exact on those and are not a symbolic algebra
  system. State the order with every exactness claim.
- **These transforms exist only for specific equations.** Cole-Hopf works for
  viscous Burgers, Miura for the KdV/mKdV pair, Backlund for a short list of
  integrable equations. This is a specialist capability, not a general
  linearization method, and no text may imply that an arbitrary nonlinear PDE
  can be linearized.
- The `n`-soliton formulas are classical (Backlund, Darboux, Hirota and
  successors). The contribution is the exact jet implementation and its
  integration with a differentiable field.
- Certificate tier: none by default. Jet-identity verification is a finite exact
  computation and is a candidate for the Lean obligation class of spec 01-11.

## 11. Open questions and risks

- **The antiderivative constant.** `antiderivative_jet` fixes a constant that is
  physically meaningful in Cole-Hopf (it sets a multiplicative constant in
  `phi`, which cancels in `u`). Verify the cancellation rather than assuming it.
- **Boundary and initial conditions transform too.** Cole-Hopf maps `u`'s initial
  data to `phi`'s through an integral; getting this wrong is the most common
  implementation error and needs an explicit test.
- **Numerical range.** `phi = exp(-integral u / (2 nu))` overflows for small `nu`
  or large `u`. A log-domain formulation is likely required, and small-`nu`
  behaviour must be measured, not assumed.
- **Falsifier.** If the direct PINN, with standard tricks, reaches within `10x`
  of the Cole-Hopf route on Burgers, the transform is a convenience rather than
  a capability.
